# Settings and profiles

Open **Advanced > Settings** to manage profiles, menu preferences, sensitivity, display and diagnostics.

## Configuration profiles

**Active Profile** switches the configuration you are editing. To make a separate working copy, enter a name in **New Profile** and choose **Create**. The selected profile and its hero settings are saved together.

| Action | Result |
| --- | --- |
| Change Active Profile | Loads that profile. Check the selected profile before editing. |
| Wait after an edit | Settings save automatically after about four seconds. |
| Save All Changes | Saves immediately. |
| Reset All Changes | Restores factory defaults across heroes. Save a separate profile first if you plan to return to your current settings. |

Toolbar presets apply a starting configuration across hero profiles, including the **All** fallback. Visuals, combos and output-device settings are kept. Use a separate profile when comparing presets.

## Menu preferences

Choose the interface **Language** and **Toggle Key** in the Menu section. **Home** is the default shortcut. Use **Application > Close** when you want to close WardenGG from its menu.

## Sensitivity and display

**Read** imports the game’s sensitivity. **Auto Counts from Sens** derives the default calibration, while **Calibrate** measures it for your setup. **Reset** restores the automatic value. Recheck both sensitivity and target screen resolution after switching your mouse settings or display.

## Troubleshooting checklist

| Symptom | First thing to check |
| --- | --- |
| Menu does not open | Check the launcher state and confirm the configured Toggle Key. |
| Changes appear to be missing | Confirm Active Profile, selected hero and selected slot. Use Save All Changes. |
| Overlay is offset | Check Target Screen and its resolution against the display running Overwatch. |
| Settings only behave differently on one hero | Compare that hero’s overrides with All and check whether Follow current hero changed the selection. |

If the issue persists, include the visible runtime version, selected profile, affected menu and precise symptom in a support ticket. Share a cropped screenshot with account details and directory paths removed.
