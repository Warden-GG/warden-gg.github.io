## Shared Launcher & PC Setup

World of Warcraft and Overwatch 2 use the same **WardenGG Launcher** and share identical Windows prerequisites (Windows 10 Pro 22H2 or Windows 11 Pro 22H2 to 25H2, TPM 2.0 enabled, Defender/AV disabled, Vulnerable Driver Blocklist and HVCI off, Secure Boot off).

- [Getting Started & Preparations](getting-started.md): required Windows settings and launcher installation for both games.
- [Before Redemption](before-redemption.md): hardware checks, `SystemChecker.exe`, and HWID reset policy.
- [Enable TPM 2.0](enable-tpm.md): check `tpm.msc` and enable PTT / fTPM by motherboard brand.
- [Launcher Troubleshooting](troubleshooting.md): launcher-wide fixes for Error 264, Driver Loading Failed, and connection issues.

## Support

If a guide does not resolve your issue, open a ticket in **#support** on Discord. Include the game (`WoW` or `Overwatch 2`), your Windows version, and the exact error or screenshot you are seeing.
