# Visuals and display

**Display > Visuals** contains player overlays, radar and field-of-view rings. **Display > World** controls markers for objects in the game world.

## Player overlays

The **Enabled** switch controls the player overlay. **Draw Enemy** and **Draw Ally** filter the teams shown. **Visible Only** limits the display to players currently visible, and **Max Distance** controls its range. Hero names, health, skeletons and other labels can be adjusted independently.

If labels overlap, reduce the visible elements, adjust their offsets, or use **Dynamic Font Scaling** so label size changes with distance.

## Radar and FOV rings

Radar has settings for size, display distance, marker size and team colors. Field-of-view rings are configurable separately. If a ring is not centered, check **Settings > Screen > Target Screen** before changing the ring itself.

## World objects

Choose the object groups you want shown, such as health packs, projectiles, deployables and barriers. Each group can have its own color and labels, together with general controls for boxes, names, icons and distance. Use **Hide Friendly Objects** to reduce clutter.

## Screen and performance

**Advanced > Settings > Screen** contains the display resolution and host-state pause settings. **Overlay frame limit**, under **Application**, caps the overlay refresh rate. Use the current overlay FPS as a readout when comparing settings on the same machine.
