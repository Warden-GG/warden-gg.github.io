# WardenGG 文档

安装指南、脚本管理与故障排查。请先确认系统要求，再按照指南逐步操作。

> **TPM 2.0 现已成为必要条件**
>
> 没有 TPM 2.0 就无法使用解锁器。请在兑换密钥或开始设置前，确认系统满足此要求。
>
> 需要帮助？查看 [检查并启用 TPM 2.0](zh/enable-tpm.md)，了解 ASUS、MSI、Gigabyte/AORUS 和 ASRock 主板的设置方法。

## 选择你需要的指南

1. [兑换前须知](zh/before-redemption.md) - 兑换前，先了解使用要求和密钥相关信息。

3. [故障排查](zh/troubleshooting.md) - 查找启动器错误、加载问题及常见故障的解决方法。
