# WardenGG 文档

魔兽世界 (World of Warcraft) 与守望先锋 2 (Overwatch 2) 的共用系统准备、启动器安装、脚本管理与故障排查指南。

> **两款游戏均必须开启 TPM 2.0**
>
> 没有 TPM 2.0 将无法使用 WardenGG。请在兑换密钥或开始设置前，查看 [检查并启用 TPM 2.0](zh/enable-tpm.md)，了解 ASUS、MSI、Gigabyte/AORUS 和 ASRock 主板的设置方法。

## 选择你需要的指南

1. [兑换前须知](zh/before-redemption.md) - 兑换前，先了解使用要求、HWID 重置和密钥信息。
2. [新手入门（魔兽世界 & 守望先锋 2）](zh/getting-started.md) - 共用系统准备、关闭 HVCI/Defender、安装启动器并启动游戏（脚本文件夹仅限魔兽世界）。
3. [守望先锋 2 首次设置图文教程](overwatch-setup.md) - 关闭垂直同步、无边框窗口化、启动器注入与灵敏度校准图文指南。
4. [故障排查](zh/troubleshooting.md) - 查找启动器错误、驱动加载问题及常见故障的解决方法。
